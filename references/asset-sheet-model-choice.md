# 出图模型与平台

- **文字和尺寸优先**：先用一张带中文视图名及少量数字的样图验证当前入口。可在 GPT Image 或其他支持文本渲染的模型上测试。字形或箭头失真时，用干净版出图并后期补标。
- **多视图一致性优先**：使用支持参考图或多图输入的模型，例如 Nano Banana 系列。提示词写清格数、排列和同一实物，核对部件是否在不同视角间移位。必要时分视角生成再拼版。
- **即梦**：用中文自然语言完整句，画幅在平台设置。尺寸与视图名称先保留，出图后核验字形。
- **合成素材**：将角色定妆、环境和屏幕配图的用途逐一写清。已生成的配图用平台的参考图挂载机制绑定，界面需要精确可读文字时可单独排版。
